Support and security

Contact support

Email info@masetek.co.uk for app help, privacy requests or a security concern. This free release has no contractual response-time or uptime SLA. Do not assume continuous monitoring or 24/7 emergency coverage. Follow your organisation's incident process for urgent operational events.

Include the app environment/version, approximate time, affected screen, reproduction steps and a sanitised screenshot. An AN asset reference can help. Do not send API tokens, passwords, full inventories or operational network details in an initial email. Agree an appropriate channel before sending sensitive diagnostics.

Common fixes

If the app cannot start, reload once and ask a Jira administrator to check the installation and permissions. If an edit conflicts, close the form, reload the latest record and reapply the intended change. During a queued privacy erasure, writes pause until processing finishes; administrators can inspect and advance the queue in Privacy.

For CSV imports, correct rejected rows and verify identifiers. Omitted columns preserve existing values; blank optional fields clear them. Completed rows remain saved after a later failure. Downloaded evidence includes a read interval and reflects recorded data, not certified completeness. Use the explicit Save evidence link if an automatic download does not begin.

Report a security issue

Email info@masetek.co.uk with a concise description and safe reproduction steps. Avoid including exploitation against other customers, credentials or unnecessary personal information. We will assess the report, coordinate the required response and provide updates as appropriate. No bug-bounty reward, certification or fixed security response SLA is promised by this page.

Provider and legal information

The app uses Atlassian Forge and Jira APIs; support email is routed through Google. Public documentation is hosted on Render. Inventory is not automatically sent to the documentation site or support mailbox. Read the Privacy policy, end-user terms and Data Processing Addendum before installation.
